# 한수런런

국가유산청 산하 청년 세계유산지킴이 팀 ‘한수’의 한양의 수도성곽 프로젝트 웹사이트입니다.

이 사이트의 목적은 **참여 현황과 배움을 보여주는 것**입니다.
신청·문의를 받는 창구가 아니므로 접수 폼이나 연락처 섹션은 두지 않습니다.
주 이용자는 어린이이며, 헤더 스위치로 어른용 문구로 바꿀 수 있습니다.

## 로컬에서 실행

```bash
./serve.sh          # http://localhost:8811
./serve.sh 3000     # 포트 지정
```

브라우저에서 `index.html`을 파일로 직접 열어도(`open index.html`) 지금은 동작하지만,
백엔드를 붙여 `fetch`를 쓰기 시작하면 CORS에 막혀 깨집니다. 처음부터 서버로 보세요.

### ⚠️ 위치 기능은 https 또는 localhost에서만 됩니다

스탬프 인증은 브라우저 보안 정책상 **보안 컨텍스트**에서만 동작합니다.

| 접속 방법 | 위치 기능 |
|---|---|
| `http://localhost:8811` | ✅ 됨 (localhost는 예외 허용) |
| `http://192.168.x.x:8811` (같은 와이파이의 휴대폰) | ❌ 차단됨 |
| `https://...` (배포 후) | ✅ 됨 |

휴대폰에서 인증을 테스트하려면 https 터널이 필요합니다.

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:8811
# 출력되는 https://....trycloudflare.com 주소를 휴대폰에서 열면 됩니다
```

## 사이트 구성

헤더 메뉴와 섹션 순서는 1:1로 일치합니다.

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | **소개** | 성곽의 가치와 한수런런이 하는 일 |
| 2 | **누적 기록** | 옛 지도 · 구간별 현황 · 환산 · 주차별 추이 |
| 3 | **어린이 배움** | 배움 3단계 · 눈높이 문답 5개 · 성곽 이야기 카드 6장 |
| 4 | **스탬프** | 참여 코드 · 순성길 코스 선택 · 위치 인증 · 이야기 열림 |
| 5 | **그림 지도** | 아이들이 그린 성곽 |
| 6 | **퀴즈** | 30문제 중 6개 무작위 출제. 보기 순서도 매번 섞임. ‘모든 문제 풀어보기’ 제공 |
| 7 | **프로그램** | 방문교육과 시민 러닝 안내 |

## 지도의 성곽선이 뜻하는 것

성곽선은 **순성길 구간마다 따로** 채워집니다.

- **색이 있는 부분** = 그 구간에서 지금까지 달린 만큼
- **흐린 점선** = 아직 남은 만큼
- 채움 비율 = 그 구간의 `km / goalKm`

그래서 한양도성 하나가 네 조각으로 나뉘어 보입니다. 사람들이 많이 달린
구간은 거의 이어져 있고, 덜 달린 구간은 크게 비어 있습니다.
**어느 구간을 많이 달렸는지가 지도에서 바로 보입니다.**

선에 마우스를 올리면 그 구간의 이름·거리·달성률이, 누르면 그 구간만 남고
나머지는 물러납니다.

구간별 수치는 `data.js` 의 `courses[].km / goalKm / runners` 이며,
합계가 `segments[]` 의 성곽 단위 값과 맞아야 합니다.
북한산성은 공식 순성길 구간이 없어 성곽 단위로 한 덩어리로 채웁니다.

### 지도 그림에 대하여

옛 회화식 지도(종이 질감·먹 산세)에 네온 성곽선을 얹은 하이브리드입니다.
성곽선은 먹 그림자 → 발광 → 코어 3겹으로 그려지고, 달린 구간 위로는
참여 인원에 비례하는 수의 빛 입자가 흐릅니다.
지도가 화면 밖으로 나가면 애니메이션이 자동으로 멈춥니다(배터리 절약).
`prefers-reduced-motion`이 켜져 있으면 입자는 움직이지 않고 고정됩니다.

지도는 소장기관 스캔 이미지를 쓰지 않고 **전부 SVG로 새로 그린 그림**이므로
별도 이용 허락이 필요 없습니다.

## 백엔드 연결

서버를 따로 빌리지 않고 **구글 스프레드시트 한 장**으로 운영합니다.
운영자는 시트에서 눈으로 검수하고, 사이트는 집계된 JSON만 받아 갑니다.

### 1. 서버 만들기

1. 구글 드라이브에서 스프레드시트를 새로 만듭니다
2. **확장 프로그램 → Apps Script** 를 열고 `backend/apps-script.gs` 내용을 붙여넣습니다
3. `setup()` 함수를 한 번 실행합니다 → 시트 4개가 자동 생성됩니다
4. **배포 → 새 배포 → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 나온 `.../exec` 주소를 복사합니다

### 2. 사이트에 연결

`data.js` 의 `api` 블록만 고치면 됩니다.

```js
api: {
  enabled: true,
  url: 'https://script.google.com/macros/s/AKfy.../exec',
  postStamps: true,
},
```

### 3. 시트 사용법

| 시트 | 하는 일 |
|---|---|
| `runs` | 러닝 인증. **승인 열이 `true` 인 행만** 집계됩니다 |
| `stamps` | 스탬프 인증이 자동으로 쌓입니다 |
| `codes` | 참여 코드 목록. 비워 두면 아무 코드나 허용 |
| `config` | `updatedAt`(기준일), `isLive`(샘플 배지 on/off) |

**`runs` 의 구간 칸에는 코스 id 를 넣습니다.** 지도가 코스 단위로 채워지기 때문입니다.

| 코스 id | 구간 |
|---|---|
| `baekak` | 백악구간 |
| `naksan` | 낙산구간 |
| `namsan` | 남산(목멱산)구간 |
| `inwang` | 인왕구간 |
| `tangchun-west` | 탕춘대성 서성구간 |
| `tangchun-east` | 탕춘대성 동측구간 |
| `bukhan` | 북한산성 (공식 순성길 구간이 없어 성곽 단위) |

목록에 없는 id 는 집계에서 건너뜁니다. 오타로 수치가 틀어지지 않게 하기 위해서입니다.

구글 폼을 만들어 응답 시트를 `runs` 로 쓰면 접수까지 자동화됩니다.

### 동작 방식

- 페이지는 **항상 `data.js` 의 값으로 먼저 그려집니다**
- 서버 응답이 도착하면 수치만 덮어쓰고 다시 그립니다
- 서버가 없거나 실패하면 조용히 더미 값으로 남습니다 — 화면이 깨지지 않습니다
- 서버가 덮어쓰는 것: 코스별·성곽별 거리와 인원 · 누적 참여자 · 주차별 · 최근 인증 · 기준일
- 서버가 건드리지 않는 것: 코스 정보, 인증지점 좌표, 교육 문구, 퀴즈 (고정 콘텐츠)

순 인원은 코스별과 성곽별을 **서버가 각각 따로 셉니다.**
여러 구간을 달린 사람이 중복 계산되지 않게 하기 위해서입니다.

### ⚠️ 보안

액세스 권한을 ‘모든 사용자’로 두면 **주소를 아는 누구나 스탬프를 보낼 수 있습니다.**
캠페인 기간에만 열거나, `apps-script.gs` 의 `SECRET` 을 채워 토큰을 요구하세요.

스탬프 기록에는 **좌표를 저장하지 않습니다.** 어린이 위치정보를 서버에 남기지
않기 위해서이며, 지점 id 와 오차값만 기록합니다.

## 참여 코드 (로그인 대신)

로그인을 두지 않습니다. 주 이용자가 어린이라, 만 14세 미만의 개인정보를
받으려면 법정대리인 동의가 필요하고 처리방침·보관기간·파기절차까지
따라옵니다. 얻는 것에 비해 부담이 큽니다.

대신 **6자리 숫자 코드**를 씁니다. 이름·이메일·전화번호를 받지 않으므로
개인정보 수집에 해당하지 않으면서, 기기를 바꿔도 기록이 이어집니다.

### 운영 방법

1. `codes` 시트에 코드를 미리 넣습니다

   | 코드 | 이름표(선택) | 발급일 | 사용중지 |
   |---|---|---|---|
   | 482913 | 3학년 2반 | 2026-09-01 | |
   | 571204 | 가족 참여 | 2026-09-01 | |

2. 방문교육이나 행사에서 코드를 나눠 줍니다
3. 참가자가 사이트에서 코드를 입력하면 그 뒤 찍는 스탬프가
   `stamps` 시트에 코드와 함께 쌓입니다

- **이름표**를 적어 두면 화면에 함께 표시됩니다 (`3학년 2반`)
- **사용중지**에 `true` 를 넣으면 그 코드는 더 이상 받지 않습니다
- `codes` 시트가 **비어 있으면 아무 코드나 받습니다** (준비 단계용)
- 코드가 없어도 인증은 됩니다. 다만 기록이 그 브라우저에만 남습니다

## 글 눈높이 전환 (어린이 / 어른)

헤더 오른쪽 스위치로 문구가 통째로 바뀝니다. **기본값은 어린이**이고
선택은 브라우저에 저장됩니다.

| 대상 | 어디에 쓰나 | 개수 |
|---|---|---|
| `data-kid="..."` | HTML 의 제목·설명 (원문은 `data-adult` 에 자동 보관) | 23 |
| `storyKid` | 인증지점 이야기 | 14 |
| `detailKid` | 코스 설명 | 6 |
| `bodyKid` | 성곽 이야기 카드 | 6 |

어린이 모드에서는 글씨와 줄 간격이 커지고, 운영용 안내(`?geodebug=1` 등)는
숨겨집니다. 다만 **도장이 기기에만 저장된다는 안내는 어린이 문구로 그대로 노출**합니다.

## 퀴즈

`data.js` 의 `quiz` 에 문항을 모아 두고, 그중 `quizPick` 개(기본 6개)를
무작위로 뽑아 냅니다. **보기 순서도 함께 섞이며 정답 위치가 따라 옮겨집니다.**

- 페이지를 열 때와 ‘다시 풀기’ 때마다 새로 뽑고 새로 섞습니다
- 결과 화면의 **‘모든 문제 풀어보기’** 를 누르면 전체 문항이 나옵니다
  (문항이 12개를 넘으면 진행 표시가 점 대신 막대로 바뀝니다)
- 문항을 추가하려면 `quiz` 배열에 `{ q, options(4개), answer, why }` 를 넣기만 하면 됩니다.
  뽑기·섞기는 자동입니다

## 공개 전 반드시 확인할 것

### 성곽 길이

출처: [서울 한양도성 공식 누리집 — 한양의 수도성곽 소개](https://seoulcitywall.seoul.go.kr/content/149.do)

| 성곽 | 길이 | 근거 |
|---|---|---|
| 수도성곽 전체 | 42.75km | 공식 명시 |
| 한양도성 | 18.6km | 공식 명시 |
| 북한산성 | 11.6km | 공식 명시 |
| **탕춘대성** | **12.55km** | ⚠️ **공식 페이지에 길이 미기재. 도출값** |

위키백과·서울시 자료의 ‘탕춘대성 약 4km’는 인왕산 동북쪽 ~ 북한산 비봉의
현존 **서성(西城)** 구간입니다. 4km 로 보면 세 성곽 합이 34.2km 라
공식 42.75km 와 맞지 않고, 그 차이 약 8.55km 가 동측 연결구간에 해당하는
것으로 보입니다. **공개 전 서울시·국가유산청에 확정 수치를 확인하세요.**

순성길 4개 구간 거리(4.7 + 3.2 + 6.7 + 4.0 = 18.6km)는 공식 총 길이와 일치합니다.

### 인증 포인트 좌표

`data.js` 의 `geo.checkpoints` 는 공개 자료 기준 근사값입니다.
주소 끝에 **`?geodebug=1`** 을 붙이면 모든 지점까지의 실측 거리가 표시되므로,
현장에서 그 값으로 좌표와 `radiusM` 을 보정하세요.
**이 검증을 하지 않으면 현장에서 인증이 실패합니다.**

### 내용 검수

국가유산청 프로젝트인 만큼 사실관계는 팀에서 한 번 읽어봐 주세요.
전부 `data.js` 한 파일에 모여 있습니다.

- 인증지점 이야기 14곳 (어른·어린이 각 버전)
- 성곽 이야기 카드 6장
- 퀴즈 30문항 (한 번에 6개씩 무작위 출제)
- 교육 실적 수치 — **지금은 예시값입니다**

### 개인정보

- 최근 인증과 그림 지도에는 **닉네임 또는 참여 코드만** 노출합니다
- 아이들 작품을 올릴 때는 **보호자 동의를 먼저** 받고, 이름은 성 없이,
  학교명은 넣지 마세요
- 스탬프에 좌표를 저장하지 않습니다

### 색상

`--w-hanyang #1f6fd8` / `--w-tangchun #f2600f` / `--w-bukhan #00a86b`
세 색은 종이 배경(`#e3d5b8`) 기준으로 색각 이상(적록·청황) 구분도 검증을
통과한 조합입니다 (최소 CVD ΔE 10.6, 일반시야 26.4).
대비가 3:1 미만이므로 **지도 위 직접 라벨과 표를 반드시 함께 유지**해야 합니다.
