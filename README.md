# 한수런런 Learn · Run 웹사이트

국가유산청 산하 청년 세계유산지킴이 팀 ‘한수’입니다. 이곳은 저희의 한양의 수도성곽 교육·러닝 프로젝트 공식 웹사이트입니다.

이 사이트의 목적은 **참여 현황과 배움을 보여주는 것**입니다.
신청·문의를 받는 창구가 아니므로 접수 폼이나 연락처 섹션은 두지 않습니다.

## 로컬에서 실행

```bash
./serve.sh          # http://localhost:8811
./serve.sh 3000     # 포트 지정
```

브라우저에서 `index.html`을 파일로 직접 열어도(`open index.html`) 지금은 동작하지만,
나중에 실데이터를 `fetch`로 불러오기 시작하면 CORS에 막혀 깨집니다.
처음부터 서버로 보는 편이 안전합니다.

### ⚠️ 위치 기능은 https 또는 localhost에서만 됩니다

스탬프 인증은 브라우저 보안 정책상 **보안 컨텍스트**에서만 동작합니다.

| 접속 방법 | 위치 기능 |
|---|---|
| `http://localhost:8811` | ✅ 됨 (localhost는 예외 허용) |
| `http://192.168.x.x:8811` (같은 와이파이의 휴대폰) | ❌ 차단됨 |
| `https://...` (배포 후) | ✅ 됨 |

휴대폰에서 인증을 테스트하려면 https 터널이 필요합니다.

```bash
brew install cloudflared
cloudflared tunnel --url http://localhost:8811
# 출력되는 https://....trycloudflare.com 주소를 휴대폰에서 열면 됩니다
```

## 누적 러닝 시각화 (`#record` 섹션)

옛 회화식 지도 위에 세 성곽의 누적 러닝 달성률을 그리는 섹션입니다.

### 파일 구성

| 파일 | 역할 |
|---|---|
| `data.js` | **데이터만** 들어 있습니다. 실데이터 연결 시 여기만 고치면 됩니다. |
| `index.html` | `#record` 섹션 마크업 + 지도 SVG(성곽선·물길·프레임) |
| `style.css` | `#record` 이하 스타일 |
| `script.js` | 산세 생성, 성곽선 채우기, 러너 파티클, 카운터, 차트, 툴팁, 지오펜스 인증, 눈높이 전환 |
| `api.js` | 백엔드 연결. 서버가 없거나 죽어 있으면 더미 데이터로 그대로 동작합니다 |
| `backend/apps-script.gs` | 구글 스프레드시트 기반 서버 (배포용) |

### 지도의 성곽선이 뜻하는 것

성곽선은 **순성길 구간마다 따로** 채워집니다.

- **색이 있는 부분** = 그 구간에서 지금까지 달린 만큼
- **흐린 점선** = 아직 남은 만큼
- 채움 비율 = 그 구간의 `km / goalKm`

그래서 한양도성 하나가 네 조각으로 나뉘어 보이고, 사람들이 많이 달린
낙산구간(94%)은 거의 이어져 있고 백악구간(66%)은 크게 비어 있습니다.
**어느 구간을 많이 달렸는지가 지도에서 바로 보입니다.**

구간별 수치는 `data.js` 의 `courses[].km / goalKm / runners` 이며,
합계가 `segments[]` 의 성곽 단위 값과 맞아야 합니다.
북한산성은 공식 순성길 구간이 없어 성곽 단위로 한 덩어리로 채웁니다.

선에 마우스를 올리면 그 구간의 이름·거리·달성률이, 누르면 그 구간만 남고
나머지는 물러납니다.

### 지도 표현

옛 회화식 지도(종이 질감·먹 산세)에 네온 성곽선을 얹은 하이브리드입니다.
성곽선은 먹 그림자 → 발광 → 코어 3겹으로 그려지고, 누적 거리만큼 차오릅니다.
달린 구간 위로는 참여 인원에 비례하는 수의 빛 입자가 흐릅니다.
지도가 화면 밖으로 나가면 애니메이션이 자동으로 멈춥니다(배터리 절약).
`prefers-reduced-motion`이 켜져 있으면 입자는 움직이지 않고 제자리에 고정됩니다.

지도는 소장기관 스캔 이미지를 쓰지 않고 **전부 SVG로 새로 그린 그림**이므로
별도 이용 허락이 필요 없습니다.

### 실데이터 연결 (Google Forms → Sheets → Apps Script)

1. 구글 폼으로 인증 접수 — 닉네임 / 구간 / 거리 / 러닝앱 스크린샷
2. 응답 시트에 `승인` 열을 두고 운영자가 검수
3. Apps Script를 웹앱으로 배포해 `data.js`와 **같은 구조의 JSON**을 반환
4. `script.js` 맨 위에서 `window.HANSU_DATA`를 fetch 결과로 교체
5. `data.js`의 `isLive`를 `true`로 바꾸면 '샘플 데이터' 배지가 사라집니다

### 백엔드 연결

서버를 따로 빌리지 않고 **구글 스프레드시트 한 장**으로 운영합니다.
운영자는 시트에서 눈으로 검수하고, 사이트는 집계된 JSON만 받아 갑니다.

### 1. 서버 만들기

1. 구글 드라이브에서 스프레드시트를 새로 만듭니다
2. **확장 프로그램 → Apps Script** 를 열고 `backend/apps-script.gs` 내용을 붙여넣습니다
3. `setup()` 함수를 한 번 실행합니다 → `runs` / `stamps` / `config` 시트가 자동 생성됩니다
4. **배포 → 새 배포 → 웹 앱**
   - 실행 사용자: **나**
   - 액세스 권한: **모든 사용자**
5. 나온 `.../exec` 주소를 복사합니다

### 2. 사이트에 연결

`data.js` 의 `api` 블록만 고치면 됩니다.

```js
api: {
  enabled: true,
  url: 'https://script.google.com/macros/s/AKfy.../exec',
  postStamps: true,
},
```

### 3. 시트 사용법

| 시트 | 하는 일 |
|---|---|
| `runs` | 러닝 인증. **승인 열이 `true` 인 행만** 집계됩니다 |
| `stamps` | 스탬프 인증이 자동으로 쌓입니다 |
| `config` | `updatedAt`(기준일), `isLive`(샘플 배지 on/off) |

구글 폼을 만들어 응답 시트를 `runs` 로 쓰면 접수까지 자동화됩니다.

### 동작 방식

- 페이지는 **항상 `data.js` 의 값으로 먼저 그려집니다**
- 서버 응답이 도착하면 수치만 덮어쓰고 다시 그립니다
- 서버가 없거나 실패하면 조용히 더미 값으로 남습니다 — 화면이 깨지지 않습니다
- 서버가 덮어쓰는 것: 누적 참여자 · 구간별 거리/인원 · 주차별 · 최근 인증 · 기준일
- 서버가 건드리지 않는 것: 코스, 인증지점 좌표, 교육 문구, 퀴즈 (고정 콘텐츠)

### ⚠️ 보안

액세스 권한을 '모든 사용자'로 두면 **주소를 아는 누구나 스탬프를 보낼 수 있습니다.**
캠페인 기간에만 열거나, `apps-script.gs` 의 `SECRET` 을 채워 토큰을 요구하세요.

스탬프 기록에는 **좌표를 저장하지 않습니다.** 어린이 위치정보를 서버에 남기지
않기 위해서이며, 지점 id 와 오차값만 기록합니다.

## 글 눈높이 전환 (어린이 / 어른)

헤더 오른쪽 스위치로 문구가 통째로 바뀝니다. **기본값은 어린이**이고
선택은 브라우저에 저장됩니다.

| 대상 | 어디에 쓰나 |
|---|---|
| `data-kid="..."` | HTML 의 제목·설명 (원문은 `data-adult` 에 자동 보관) |
| `storyKid` | 인증지점 이야기 14곳 |
| `detailKid` | 코스 설명 6개 |
| `bodyKid` | 성곽 이야기 카드 6장 |

어린이 모드에서는 글씨와 줄 간격이 커지고, 운영용 안내(`?geodebug=1` 등)는
숨겨집니다. 다만 **도장이 기기에만 저장된다는 안내는 어린이 문구로 그대로 노출**합니다.

## 공개 전 반드시 확인할 것

- **성곽 실측 길이** — `data.js`의 `lengthKm`은 자료마다 수치가 다릅니다.
  국가유산청 공식 수치로 확인 후 확정하세요.
  (한양도성 18.6km / 탕춘대성 5.1km / 북한산성 11.6km 로 입력해 둠)
- **개인정보** — 최근 인증에는 닉네임만 노출합니다. 실명·상세 위치·연락처를 넣지 마세요.
- **성곽 색상** — `--w-hanyang #1f6fd8` / `--w-tangchun #f2600f` / `--w-bukhan #00a86b`
  세 색은 종이 배경(#e3d5b8) 기준으로 색각 이상(적록·청황) 구분도 검증을 통과한
  조합입니다 (최소 CVD ΔE 10.6, 일반시야 26.4). 대비가 3:1 미만이므로
  **지도 위 직접 라벨과 표를 반드시 함께 유지**해야 합니다.
- **인증 포인트 좌표** — `data.js`의 `geo.checkpoints`는 공개 자료 기준 근사값입니다.
  주소 끝에 `?geodebug=1`을 붙이면 모든 포인트까지의 실측 거리가 표시되므로,
  현장에서 그 값으로 좌표와 `radiusM`을 보정하세요.
- **스탬프 저장** — 지금은 브라우저 `localStorage`에만 저장됩니다.
  기기를 바꾸면 사라지고 운영자도 볼 수 없습니다. 실제 운영에는 백엔드가 필요합니다.
