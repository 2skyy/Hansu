# 한수런런 | Learn, Run

국가유산청 청년 국가유산지킴이 팀 ‘한수’의 한양의 수도성곽 교육·러닝 프로젝트 웹사이트입니다.

## 파일 구성

- `index.html`: 웹사이트 본문 구조
- `style.css`: 디자인 및 반응형 스타일
- `script.js`: 모바일 메뉴 동작

## 수정할 부분

`index.html`에서 아래 항목을 실제 정보로 바꾸세요.

- 신청 폼 링크: `https://forms.gle/`
- 인스타그램 링크: `https://www.instagram.com/`
- 문의 이메일: `hansu@example.com`

## GitHub Pages 업로드 방법

1. GitHub에서 새 저장소를 만듭니다. 예: `hansu-runrun`
2. 이 폴더 안의 파일 3개를 업로드합니다.
3. 저장소의 Settings > Pages로 이동합니다.
4. Source를 Deploy from a branch로 설정합니다.
5. Branch를 main, folder를 /root로 선택합니다.
6. 저장하면 `https://아이디.github.io/hansu-runrun/` 형태의 주소가 생성됩니다.
